## 启用要点

在哪里执行：在 OpenCode 里执行，直接改当前项目的文件。不建沙盒。

用哪些执行模型：难任务和审查用 `<供应商>/<强模型>`，机械任务用 `<供应商>/<便宜模型>`。同一供应商里价格相同的几档，强模型选能力更强的那一个，便宜模型选更低档的那一个。派单写成 `<供应商>/<模型>#<档位>`。

档位表：

| 类型 | 执行 | 审查 |
|---|---|---|
| A 纯机械 | `<供应商>/<便宜模型>#<低档>` | `<供应商>/<强模型>#<低档>` |
| B 固定写代码 | `<供应商>/<便宜模型>#<低档>` | `<供应商>/<强模型>#<低档>` |
| C 常规实现 | `<供应商>/<便宜模型>#<中档>` | `<供应商>/<强模型>#<中档>` |
| D 较难 | `<供应商>/<强模型>#<中档>` | `<供应商>/<强模型>#<高档>` |
| E 高风险 | `<供应商>/<强模型>#<高档>` | `<供应商>/<强模型>#<高档>`，多路 |
| F 预调研和规划 | `<供应商>/<强模型>#<中档>` | 无 |

结果不合格才升一档，顺序是 `<低档>`、`<中档>`、`<高档>`。最高档要用户同意。审查档位不低于同一行的执行档位。E 类多路审查。

额度用完或限流时：停下来告诉用户。不把难任务改派给便宜模型，也不把机械任务改派到强模型上。不自动换方案。
